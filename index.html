Agent · Claude Code · 545 tests

Lilith

A chief of staff that reads six sources, so I read one screen.

  • 66 sources, polled with saved cursors
  • 77 plain rules, no model
  • 545545 tests
How it works

It polls mail, Discord, meeting transcripts, the calendar, the team's task hub and the Claude Code sessions I have running. One reader model, with every tool switched off, is the only part that sees raw text; seven plain rules then decide what needs me now, with no model in that loop. Its own actions wait in a review queue, and it never writes to an outside service.

Cloudflare Workers · D1 · Gemini

Atlas

A money assistant that never does its own sums.

  • 00 runtime dependencies
  • 4242 test files
  • 1 min1 min cron cycle on D1
How it works

You tell it on Telegram, by voice or text, what you spent. The model only reads the sentence and words the reply; every number comes from tested code that counts in whole paisa, never floats, so the guard against credit-card debt is never wrong about money. A Cloudflare Worker with D1 runs a cron every minute, so reminders and the morning digest arrive before you ask.
